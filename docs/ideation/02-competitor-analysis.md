# 경쟁사 분석 — 크루·단체 접수 + 멤버별 개별 결제

- 작성일: 2026-10-01
- 대상 제품: 크루장이 단체 참가를 만들면 멤버가 초대 링크로 각자 신청·결제하고, 시스템이 정원·대기자 승격·마감 확정·단체별 정산을 처리하는 B2B2C 예약 플랫폼 (주최자 – 크루장 – 멤버)
- 수정: 2026-10-02 러너블을 인접 경쟁 → 직접 경쟁으로 재분류 ([02-1](02-1-competitor-runable.md))
- 수정: 2026-10-05 휴먼피봇 사업 모델·실제 대회 단체 접수 방식 조사 반영 (3장 ①, 7장 1번)
- 조사 방법: 웹 검색 + 공개 페이지 확인. 가격·내부 기능은 공개되지 않은 곳이 많아 "확인 불가"로 표기했다.

## 0. 출발 가설 검증

| 가설 | 결과 | 근거 |
|---|---|---|
| 2026 DMZ 평화마라톤은 단체 신청 시 개별 결제가 안 된다 | **사실** | FAQ: 단체 신청은 "시스템 구조상 단체장 명의로 일괄결제만 가능". 개별 결제를 원하면 각자 신청·결제 후 대표자가 명단(성명·생년월일·연락처)을 정리해 사무국에 연락 |
| 국내 단체 접수는 대표자 중심 수작업이 일반적이다 | **대체로 사실 (일부 대회 기준)** | 검색 결과상 엑셀 양식 다운로드 → 참가자 정보 입력 → 업로드 → 단체명으로 일괄 입금 방식이 확인됨 (서울평화마라톤 등). 전수 조사는 아님 |
| 참가권 양도는 공식 창구가 없다 | **사실, 단 '금지'가 원인** | MBN 서울마라톤, 중소기업인 마라톤 등 다수 대회가 양도·대리 참가를 약관으로 금지. 참가비에 보험이 포함되어 안전 문제도 있음. DMZ도 마감 후 취소·환불·양도 불가 |

→ 결론: **"같이 신청하고 싶지만 결제는 각자"라는 요구가 운영자 수작업으로 넘어간다**는 문제는 실제로 존재한다. 반면 **양도는 시장 빈틈이 아니라 주최자 정책상 금지 영역**이므로 핵심 기능으로 내세우면 안 된다.

## 1. 시장 개요

- **시장 규모**: 신뢰할 만한 공개 수치를 찾지 못했다. 추정치를 만들지 않고 비워 둔다 (필요 시 `market-sizing`으로 별도 추정).
- **시장 분위기 (2026 기사 기준)**
  - 접수 경쟁이 심해져 "완주보다 접수가 힘들다"는 말이 나온다.
  - 뉴발란스·코오롱스포츠 등은 제품 구매 고객에게만 참가권을 주는 **패키지 판매**로 대응 → 대형 브랜드는 자기 대회를 직접 운영하고 있어 **우리 타깃이 아니다**.
  - 천안 이봉주 마라톤: 공식 접수 전에 동호회 등 약 1,000명의 명단이 운영사에 먼저 전달되어 "특혜 통로" 논란. → **단체 접수의 공정성·투명성**이 사회적 이슈가 되었다.
    - 후속 보도: 접수 당일 서버가 마비에 가까운 사이 동호회 8곳 이상·직장 단체 **1,140명이 이메일로 따로 접수**됐다. 홈페이지 접수 6,170명과 합쳐 7,310명으로 정원 7,000명을 넘었고, **1,140명 등록은 전부 무효** 처리됐다. 체육회는 접수 기간 연장·코스별 접수·추첨제를 검토 중이다. 단체 접수를 정식 기능 없이 수작업으로 하면 사고가 난다는 사례다 (운영 대행사는 확인 불가).
  - **대회 양극화**: 인기 대회는 금방 마감되고(MBN 서울마라톤 20분, 디즈니런 인천 1.5만 명 약 3시간), 중소 대회나 짧은 종목은 2차 모집을 한다(2026 춘천연합마라톤 2차 모집, 뉴시스 바다마라톤 5km·10km 2차 모집). 2차 모집이 정원 미달 때문인지는 [추정].
- **고객 구분**
  - 주최자: 지자체·언론사·중소 대회 운영사
  - 크루장(대표자): 단체 신청을 모으고 돈을 걷는 사람
  - 멤버: 크루원 개인
- **성공 요인**: 주최자 확보(공급), 결제 신뢰, 접수 오픈 시 안정성, 크루 쪽 사용자 기반

## 3. 경쟁사 프로필

### ① 휴먼피봇 — 애니스포츠 (접수 솔루션, 국내 선두급)

- **현황**: 14년간 300개 이상 행사, 약 300만 명 접수 처리 (자사 홈페이지 기준). 마라톤·걷기·축구·자전거 행사 접수 솔루션. 네이버 스포츠 콘텐츠 제공사. 모회사는 웹·마케팅 대행사로, 2025년 10월 노코드 웹 제작 도구 '디자인피봇'도 냈다. 마라톤 접수 전문 회사는 아니다.
- **사업 모델**: 대회마다 접수 사이트를 만들어 주는 **제작 대행 + 접수 솔루션("Anysports SNS")**. 기획·개발·디자인을 묶어 맡는다. 자체 홈페이지가 있는 주최자에게는 접수 시스템만 붙여 주기도 한다.
- **돈의 흐름**: **결제 대행이 아니다.** 대회 개인정보 처리방침에 휴먼피봇은 "홈페이지 개발·유지보수" 위탁업체로만 적혀 있고, 결제는 주최·주관사가 계약한 PG(토스페이먼츠 등)가 맡는다. 카드 결제명도 주관사 이름으로 찍힌다 [사실, 기살리기·경주벚꽃·더레이스]. 참가비는 PG에서 주최자 계좌로 바로 간다 [추정]. 지자체 체육회 대회 중에는 PG 없이 계좌이체로 받는 곳도 있다 [사실, 대청호].
- **강점**: 개인/단체 온라인 접수·결제, 관리자 화면(종목·정원·기념품 설정, 결제자/미결제자/환불자 관리, **엑셀 업로드·다운로드**, 보험 가입 페이지, 통계), 대기열(경주벚꽃 `/wait.html` 확인), 주최자와의 오랜 거래 관계. 인기 대회 다수 보유 (아래 표).
- **실제 대회의 단체 접수 방식** [사실, 각 대회 FAQ·요강]

  | 대회 | 단체 접수 | 결제 | 단체 할인 |
  |---|---|---|---|
  | 중소기업인 기살리기 마라톤 (2026.10) | 2인 이상 가능 | **단체장 일괄 결제**. 결제 후 인원 추가 불가, 단체 환불은 이메일 | 안내 없음 |
  | 경주벚꽃마라톤 (정원 1.5만) | **개인 접수만** | 각자 결제 후 엑셀 단체 양식을 사무국에 이메일 → 수작업 단체 전환 | 안내 없음 |
  | 더 레이스 서울 21K | **단체 접수 없음** | 개인 카드 결제만 | 해당 없음 |
  | 청원생명쌀 대청호마라톤 | 2인 이상이면 단체명 필수 | 계좌 입금. 일괄인지 개별인지 확인 불가 | 안내 없음 |

  솔루션 소개에는 "단체장이 단체원에게 입력용 링크를 주는 기능"이 있지만, 위 대회들은 쓰지 않는다. **크루원이 각자 결제하면서 같은 단체로 묶이는 흐름은 어디에도 없다.**
- **러너 계정**: 통합 계정이 없다. 대회마다 도메인이 따로이고, 이름·생년월일·비밀번호로 비회원 신청한다. anysports.net은 대회 일정 모음 사이트이고, 크루 소개를 올릴 수 있지만 대회 신청과 연결되지 않는다. 애니스포츠 앱은 구글 플레이에서 내려가 있다 (2026-10-05 확인).
- **가격**: 비공개 (노션 문의 폼). 건별 견적 방식으로 보인다 [추정].
- **위협**: 같은 기능을 추가하면 기존 주최자 고객에게 바로 퍼진다. 다만 대행사라 기능을 대회마다 주최자가 켜야 하고, 러너 계정이 없어 **크루 단위 기록은 쌓기 어렵다.**
- **우리에게 주는 의미**
  1. 단체 개별 결제는 **실제로 비어 있는 자리**다.
  2. 주최자는 지금 참가비를 자기 계좌로 바로 받는다. 우리가 결제를 모아 정산하는 마켓플레이스는 주최자 입장에서 **수수료 + 정산 지연**이 더해지는 구조라 진입 장벽이 높다. 반면 경주벚꽃처럼 **엑셀 단체 양식을 받는 대회는 주최자 협조 없이 명단 내보내기로 바로 붙을 수 있다** (5장 포지셔닝의 내보내기 방향과 같다).
  3. 경쟁자이면서 연동 상대가 될 수도 있다. 관리자 화면에 엑셀 업로드가 있어, 우리 명단을 그 형식에 맞추면 된다 [추정].

### ② 레이스플랜 / 원시스템 (접수 솔루션)

- 레이스플랜: 마라톤·사이클 등 대회 웹사이트·접수·결제 솔루션 (검색 결과 기준). 사업 소개 페이지가 로그인으로 막혀 상세 **확인 불가**.
- 원시스템: 대회 접수·관리 솔루션 (검색 결과 기준). 홈페이지 본문 **확인 불가**.
- → 후속 조사 필요: 실제 이들이 운영하는 대회 접수 페이지에 들어가 단체 접수 흐름 확인.

### ③ 대회 자체 접수 시스템 (DMZ 평화마라톤 등)

- **강점**: 주최자가 직접 통제.
- **약점**: 단체 = 대표자 일괄 결제, 개별 결제 시 사무국 수작업 연락. 취소·환불은 전화·이메일. TTCO 할인 같은 혜택은 단체 신청에 적용 안 됨.
- **의미**: 우리 문제 정의의 **가장 직접적인 증거**.

### ④ RunSignup / Race Roster (해외)

- **RunSignup**: 접수 중 또는 접수 후 팀 생성·가입, 팀 크기·성별·나이 제한, 비밀번호 가입, 팀 캡틴 리포트, **팀 인원이 목표에 도달하면 할인 + 자동 환불**. 제공 시 참가자의 30%가 팀에 가입, 평균 팀 인원 7명 (자사 자료).
- **Race Roster**: 팀 생성·가입, 단체용 등록 코드(나중 결제·청구서 옵션).
- **의미**: **기능 자체는 해외에서 이미 표준**이다. "세계 최초"가 아니라 "국내 크루 문화에 맞춘 완결된 흐름"이 차별점이다. 특히 RunSignup의 "목표 인원 도달 시 할인 + 자동 환불"은 우리 Saga 설계에 그대로 참고할 만하다.

### ⑤ 크루 운영 앱 (Crewda 등)

- **Crewda**: 크루 일정 통합, 원탭 참석 응답, 대회 정보 보기, QR 초대, 역할 구분(크루장·운영진·멤버). 2024년 출시, 리뷰 거의 없음.
- **런메이트 크루 / 러너온 / TT러닝**: 일정·출석·채팅·기록·리더보드.
- **빈틈**: 대회 단체 접수, 회비·참가비 결제, 정산은 확인되지 않음.
- **의미**: 크루장이 이미 "구글폼 없이 인원 파악"을 원한다는 신호. 동시에 **크루 기능만으로는 해자가 안 된다**(무료 앱이 많음). 결제·접수까지 이어지는 게 차이.

## 4. 차별화 기회

1. **단체 신청 + 멤버별 개별 결제 + 대표자 현황판**: 국내 대회에서 수작업으로 넘어가는 지점을 시스템으로 닫는다. 해외에는 있으나 국내에서는 확인되지 않음.
2. **투명한 단체 정원 배정**: 천안 사례처럼 단체 접수가 "특혜"로 의심받는다. 주최자가 단체 몫 정원·신청 기간·배정 규칙을 **미리 공개**하고, 모든 배정을 기록(감사 로그)으로 남기면 공정성이 차별점이 된다.
3. **대회를 넘어 이어지는 크루 계정**: 접수 솔루션은 대회마다 사이트가 따로라 러너·크루 이력이 끊긴다. 크루와 멤버 정보가 다음 대회에 그대로 이어지는 게 기존 업체가 구조상 하기 어려운 부분.
4. **목표 인원 연동 할인 + 자동 환불**: RunSignup 방식을 국내에 적용. Saga 시연 장면으로도 좋다.
5. **양도 대신 "주최자 설정형 대체 참가"**: 양도를 기본 기능으로 두지 않고, 주최자가 허용한 대회에서만 같은 단체 안 대기 멤버로 교체(본인 정보·보험 재등록 포함). 금지 대회에서는 아예 꺼진다.

## 5. 포지셔닝 제안

> **"대회마다 흩어지는 단체 신청을, 크루가 계속 쓰는 하나의 흐름으로."**
> 주최자에게는 단체별로 확정된 명단과 정산을, 크루장에게는 돈 걷기 없는 단체 신청을, 멤버에게는 본인 결제와 상태 확인을.

- **주최자 솔루션과 정면 경쟁하지 않는다.** 처음부터 휴먼피봇 같은 업체를 대체하려 하면 주최자 영업에서 진다. 주최자 쪽은 기존 시스템이 받을 수 있는 형식(엑셀 명단 등)으로 **내보내기**를 제공하고(헥사고날의 출력 포트), 점차 직접 연동으로 넘어간다.
- **노릴 곳**: 중소 지역 대회 주최자, 크루 단위 참가가 많은 대회.
- **피할 곳**: 대형 브랜드 대회(자체 운영·패키지 판매), 대형 선착순 대회의 트래픽 경쟁.

## 6. 위험과 확인할 점

| 위험 | 내용 | 대응 |
|---|---|---|

| 돈의 흐름 규제 | 우리가 멤버 결제를 받아 주최자에게 넘기면 결제 대행·정산 관련 규제 대상일 수 있다 | **법적 확인 필요.** 초기에는 PG의 하위몰·분리 정산 기능을 쓰는 방식 검토 |
| 주최자 협조 | 주최자가 외부 단체 명단을 받아줄지 | 중소 대회 주최자 3~5곳 인터뷰 |
| 크루장 수요 크기 | 크루당 대회 단체 신청이 연 몇 회인지 | 크루장 5~10명 인터뷰 |
| 공정성 역풍 | 단체 접수 자체가 "특혜"로 보일 수 있다 | 단체 정원 공개·기록을 기본값으로 |
