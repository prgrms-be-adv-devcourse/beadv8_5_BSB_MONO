# 경쟁사 심층 분석 — 마라톤GO (marathongo.co.kr)

- 작성일: 2026-10-02
- 대상 제품: 크루 단체 대회 접수 + 크루원별 개별 결제 마켓플레이스 ([03 문제 정의](03-problem-definition.md) 기준)
- 조사 방법: 마라톤GO 웹사이트 직접 확인 + 웹 검색(앱스토어). 앱 내부는 보지 않았다.
- 표기: **[사실]** 출처로 확인 / **[추론]** 사실에서 끌어낸 해석 / **확인 불가** 공개 자료로 못 찾음

## 0. 핵심 결론

마라톤GO는 **대회 정보를 모아 보여 주는 사이트**다. 접수·결제는 하지 않는다. [02 경쟁사 분석](02-competitor-analysis.md)의 '인접 경쟁' 분류가 맞다. 직접 경쟁자라기보다 우리 서비스로 사람을 보내 줄 수 있는 **유입 경로(제휴 후보)**에 가깝다.

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 운영 | 개인 개발자(박지혁)로 보인다. 사이트 하단에 회사 정보가 없다 **[사실]** |
| 제공 기능 | 국내·해외 대회 일정, 러닝화 정보, **크루 목록**, 기록 계산기(페이스·완주 예상·칼로리·심박존), 뉴스, 커뮤니티 'GO 라운지' **[사실]** |
| 플랫폼 | 웹 + iOS·안드로이드 앱. iOS 2.0.0은 6월 출시, 평가 수가 적어 점수 미표시 **[사실]** |
| 수익 | **광고**. 대회 상세 페이지 1개에 광고 6개, 앱도 광고 포함 무료 **[사실]** |
| 접수 방식 | "신청하기"를 누르면 **대회 공식 접수 사이트로 이동**. 예: 고구려마라톤 → 러너블 상품 페이지 (`utm_source=marathongo` 표시) **[사실]** |
| 정보 관리 | 고구려마라톤 페이지에 2025년 정보가 그대로 남아 있었다. 업데이트가 늦은 대회가 있다 **[사실]** |

## 2. 크루 목록

- 약 **280개** 크루 등록 (페이지당 약 24개 × 12페이지) **[사실]**
- 내용은 각 크루 **인스타그램 소개글을 옮긴 수준**: 지역, 정기런 일정, 연락 링크 **[사실]**
- 가입·참석 신청 기능 없음. "모집 여부는 크루 홈페이지에서 확인" 안내. 목록 수정·추가는 요청 버튼으로만 받는다 **[사실]**

## 3. 우리 제품에 주는 의미

1. **크루가 실제로 쓰는 도구가 드러난다.** 크루 소개글의 연락 링크는 카카오톡 오픈채팅, 소모임 앱, 네이버 밴드, 구글폼·네이버폼, 인스타그램 DM이다. 03 문서의 R1(카톡 + 구글폼 + 계좌이체)을 뒷받침한다 **[사실: 링크 확인 / 추론: 대회 단체 신청에도 같은 도구를 쓸 것]**
2. **진짜 경쟁 상대는 카톡·밴드·소모임일 수 있다.** 크루장은 이미 이 도구로 사람을 모은다. 우리는 "단체 신청만큼은 확실히 편하다"를 보여 줘야 한다 **[추론]**
3. **제휴 후보.** 정보를 보여 주고 공식 접수 사이트로 사람을 넘기는 구조라, 우리 단체 접수 페이지도 같은 방식으로 연결될 수 있다 **[추론]**
4. **위협은 낮다.** 개인 운영 + 광고 수익 정보 사이트라 결제·정산까지 만들 가능성은 낮다 **[추론]**
